## 步骤 0 准备数据

- **点击「开始预处理」**：
  - 系统对当前连接的数据库执行一次预处理，识别社群结构、逐条内容的情感与话题、
    转发传播链路、活跃阶段、用户影响力与角色等，并把结果写回数据库。

## 步骤 1 舆情生命周期

页面把舆情过程自动切成四个阶段：**潜伏期 → 爆发期 → 扩散期 → 衰退期**

### 舆情生命周期主轴

展示不同时间段的行为事件量以及情感分数。通过时间轴伸缩可以具体到某个时间段。



### 拆解维度

用户可以通过选择拆解维度具体化两个子图：

| 选项 | 两个构成图 |
|---|---|
| 行为类型 | 按 发帖/转发/评论/点赞/刷新/搜索…… 拆分 |
| 情感极性 | 按 正面/中性/负面 拆分 |
| 关键角色 | 按 意见领袖/讨论发起者/活跃用户/普通传播者/边缘用户 拆分 |
| 影响力分层 | 按 头部/腰部/长尾 拆分 |
| 行为标签 | 按 内容生产者/活跃互动者/潜水观望/沉默用户 拆分 |
| 话题 | 按帖子话题标签拆分 |
| 推荐驱动 | 按「推荐驱动 / 自然到达」拆分 |

### 模式切换：整体走势 / 阶段对比

页面右上角可以切换两种模式：

- **整体走势**：阶段卡片 + 主轴 + 堆叠流图 + 阶段构成图。
- **阶段对比**：选两个阶段 A、B，并排给出两边的总量与情感、推荐占比，并对所选拆解维度的每个桶计算 lift = ratio_b / ratio_a。lift>1 表示该桶在 B 阶段占比变大，<1 表示变小。

## 步骤 2 关键群体识别

### 群体划分维度

决定「把所有用户按什么特征切成群体」。切换后立即重新查询。可选 9 项：

| 选项 | 把人群切成…… |
|---|---|
| 关键角色 | 意见领袖 / 讨论发起者 / 活跃用户 / 普通传播者 / 边缘用户 |
| 影响力分层 | 头部 / 腰部 / 长尾 |
| 行为标签 | 内容生产者 / 活跃互动者 / 潜水观望 / 沉默用户 / 普通参与者 |
| 社群 | 按关注网络自动检测出的社群编号 |
| 性别 / 地区 / 职业 / 账号类型 / 内容偏好 | 按对应的用户画像字段（依赖画像数据，缺失时多为「未知」） |

### 条件组合

除了群体划分维度，还可以添加多条条件组合。最终只渲染符合所有选择条件的部分。

### 三块视图

1. **群体分布散点图**：横轴=群体总活跃度，纵轴=群体平均影响力，气泡大小=人数，颜色冷暖=关键度。
2. **群体关键度排名**：关键度 = 规模×25% + 平均影响力×30% + 活跃度×20% + 事件量×25%。
3. **群体明细表**：每个群体一行，含人数、关键度、平均影响力、事件量、意见领袖数、情感构成等，列可排序。

### 模式切换：标准 / 对比基线 / A vs B

页面右上角三选一：

| 模式 |      | 视图变化 |
|---|---|---|
| 标准（默认） |      | 同上三视图 |
| 对比基线 |  | 排名图换成 **基线偏离条（lift − 1）**，可在标题下拉切换 lift 维度：人均事件 / 推荐驱动 / 负面占比 / 正面占比 / 影响力。表格右侧新增 lift 列与情感差列。基线在表头标出（人均×事件、推荐占比、负面占比、平均情感）。 |
| A vs B |  | 顶部出现两群体选择条，下方并排两张大卡片：每项指标在 B 侧标注 +/− 差量；情感和占比类用分差/百分点差，量用数量差。 |

**lift 解读**：lift = 该群体的指标 / 全体加权平均。≈1.00 与基线一致；≥1.30 用红色 danger 标签，1.05–1.30 用 warning 橙色，≤0.70 用 success 绿色（表示显著低于基线）。

## 步骤 3 关键用户识别

### 关键角色

- **全部**：不限角色。
- **意见领袖 / 讨论发起者 / 活跃用户 / 普通传播者 / 边缘用户**：只看该角色的用户。

### 排序依据

决定明细表与排名图按什么排序：

| 选项 | 含义 / 适合找的人 |
|---|---|
| 影响力分数 | 综合粉丝、被转发、获赞、发帖、网络地位的加权分——综合最有影响力的人 |
| PageRank | 关注网络中的结构地位——「被重要的人关注」的人 |
| 粉丝数 | 单纯粉丝多的人 |
| 被转发数 | 内容被转发最多——传播力最强的人 |
| 获赞数 | 内容最受认可的人 |
| 活跃度 | 行为事件最多——最「勤」的人 |
| 原创数 | 发原创帖最多——内容产出最多的人 |

### 聚焦阶段

- **选某阶段**：只保留在该阶段有过行为的用户。
- **留空**：不按阶段过滤。

### 数量

明细表与查询返回的用户条数上限（10–200）。

### 条件组合

与关键群体部分一致，可缩小用户范围。

### 三块视图

1. **角色构成**（环形图）：当前筛选结果里各角色的人数占比。
2. **关键用户排名**（条形图）：前 20 名，长度=「排序依据」所选指标的值。
3. **关键用户明细表**：每人一行，含角色、影响力、分层、粉丝、PageRank、原创/转发/被转发/获赞、
   活跃度、行为标签、社群等，列可排序。

## 步骤 4  个体溯源

在关键用户明细表点击某一行后弹出：

面板内容：

| 区块 | 含义 |
|---|---|
| 画像栏 | 角色、影响力分层、行为标签、所属社群、粉丝/关注、影响力分、被转发、获赞、活跃度、性别、职业 |
| 行为构成（环形图） | 此人全过程各类行为（发帖/转发/评论/点赞/刷新……）的占比 |
| 各阶段活跃度（柱状图） | 此人在潜伏/爆发/扩散/衰退四阶段分别有多少行为——看他是早期发起型还是后期跟风型 |
| 行为轨迹（堆叠柱） | 逐小时的行为序列，按行为类型堆叠——看他的参与节奏 |
| 影响力获取路径 | 此人发布内容的**被转发 / 评论 / 点赞累计曲线**，红色散点是每一次被转发的事件，气泡大小=来源用户的影响力。曲线陡升通常意味着被某个大 V 转发；下方列出「主要扩散来源」前 6 人（按 转发×3+评论×2+点赞 加权），陈列名、角色、影响力、粉丝。回答「TA 是被谁带火的」 |
| 发布内容列表 | 最近的原创/转发，带情感标签、所属阶段、点赞/转发/评论数、传播级联规模与深度 |

## 附录

### A. 维度

**用户维度**
- 社群：依据关注网络自动检测的社群编号。
- 影响力分层：头部（影响力前 10%）/ 腰部（10–40%）/ 长尾（其余）。
- 行为标签：内容生产者（以发帖转发为主）/ 活跃互动者（以评论点赞为主）/ 潜水观望（以刷新搜索为主）/ 沉默用户（以「不操作」为主）/ 普通参与者。

**内容维度**

- 话题：帖子的 `#话题#` 标签，无标签时按关键词归类。
- 情感极性：正面 / 中性 / 负面。

**行为维度**

- 行为类型：发帖、转发、评论、点赞、关注、刷新、搜索、看热搜、不操作、注册。
- 推荐驱动：该互动的对象帖子是否曾被推荐给该用户。

**时间维度**
- 舆情阶段：潜伏期 / 爆发期 / 扩散期 / 衰退期。
- 小时：按自然小时聚合。

### B. 关键角色判定规则
| 角色 | 判定条件（按优先级） |
|---|---|
| 意见领袖 | 影响力分层=头部，且被转发或获赞 > 0 |
| 讨论发起者 | 发过级联规模 ≥ 3的原创帖 |
| 活跃用户 | 行为事件数处于全体前 15% |
| 普通传播者 | 有过转发行为 |
| 边缘用户 | 以上都不满足 |

### C. 影响力分数公式
`log(粉丝+1)×3 + log(被转发+1)×2.5 + log(获赞+1)×1.5 + log(原创数+1)×2 + PageRank×50`

### D. 生命周期分期算法
统计事件量的逐小时曲线并做 3 点平滑：
- **潜伏期**：从开始到事件量首次达到峰值 25% 之前。
- **爆发期**：从该点上升至峰值。
- **扩散期**：从峰值到事件量回落至峰值 50% 之前的高位平台。
- **衰退期**：其余。
数据量过少时退化为按事件数四等分。

### E. 设计依据与相关文献

**四阶段切分（潜伏 / 爆发 / 扩散 / 衰退）**

阶段化是舆情研究里很早就有的做法。Downs 在 1972 年提出的 "issue-attention cycle" 把公共议题归为五段（[原文](https://www.nationalaffairs.com/public_interest/detail/up-and-down-with-ecologythe-issue-attention-cycle)），后来 Vasterman 在 2005 年讨论 media-hype 时延续了这种"上升—峰值—回落"的描述（[SAGE / DOI: 10.1177/0267323105058254](https://journals.sagepub.com/doi/10.1177/0267323105058254)）。统计上，Crane 与 Sornette 用响应函数把社交反应分成外生/内生 × 临界/亚临界四类，给出了把曲线切段的依据（[PNAS 2008](https://www.pnas.org/doi/10.1073/pnas.0803685105)）；Yang 与 Leskovec 进一步整理出六种典型时间形状（[WSDM 2011](https://dl.acm.org/doi/10.1145/1935826.1935863)）。

**lift 作为阶段间 / 群体间的对比度量**

lift 这个词来自 Agrawal & Srikant 的关联规则挖掘工作（[VLDB 1994 ](https://www.vldb.org/conf/1994/P487.PDF)），等价于流行病学里的 rate ratio 与 A/B 测试里的相对提升。

**舆情事件可视分析的同类系统**

阶段卡片 + 堆叠流 + 阶段构成对比这一组合，在以下系统里能找到原型：

- ThemeRiver（Havre 等, [InfoVis 2000](https://ieeexplore.ieee.org/document/885098/) , [TVCG 2002](https://ieeexplore.ieee.org/document/981848/)）：主题随时间的份额变化，本系统的"构成随时间演化"流图直接对应。
- LeadLine（Dou 等, [VAST 2012](https://ieeexplore.ieee.org/abstract/document/6400485/)）：事件生命周期 + 跨阶段主题与人物剖面。
- TIARA（Wei 等, [KDD 2010 PDF](https://shixialiu.com/publications/kddtiara/paper.pdf)； Liu 等, [ACM TIST 2012](https://dl.acm.org/doi/10.1145/2089094.2089101)）：文本流的阶段化主题剖面。
- Whisper（Cao 等, [TVCG 2012](https://ieeexplore.ieee.org/abstract/document/6327271)）、EventThread（Guo 等, [TVCG 2018](https://ieeexplore.ieee.org/document/8017612/)）：社交媒体事件随阶段的传播者与情绪剖面。
