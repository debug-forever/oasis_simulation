# 可视分析操作手册

> 本手册逐控件拆解可视分析的完整操作流程，并说明**每一个选项在选择不同值之后系统会发生什么变化**。
> 配套架构说明见 `VISUAL_ANALYTICS_GUIDE.md`。

整个分析分布在三个页面，对应分析的三个递进层次：

| 页面 | 菜单入口 | 分析层次 |
|---|---|---|
| 舆情生命周期 | `舆情生命周期` | 宏观：舆情整体如何随时间演化 |
| 关键群体识别 | `关键群体识别` | 中观：哪类人群在主导舆情 |
| 关键用户识别 | `关键用户识别` | 微观：具体哪些人是核心，单人轨迹如何 |

三个页面顶部都有一条**分析路径指示条**，高亮当前所处环节；并共享一条「数据状态条」。

---

## 步骤 0 · 准备数据（数据状态条）

位置：三个页面顶部都有，逻辑相同。

### 状态 A：当前仿真库尚未预处理
界面显示「当前仿真库尚未预处理」+ **开始预处理** 按钮。

- **点击「开始预处理」**：
  - 系统对当前连接的数据库执行一次预处理，识别社群结构、逐条内容的情感与话题、
    转发传播链路、活跃阶段、用户影响力与角色等，并把结果写回数据库。
  - 处理期间按钮转圈，百用户级仿真库约数秒，万用户级约数十秒。
  - 完成后状态条变为状态 B，三个分析页的图表自动加载。
  - 处理失败会弹红色提示，常见原因：数据库为空、表结构不符。

### 状态 B：数据已就绪
界面显示数据库名、用户/内容/事件/社群规模、处理时间 + **重新处理** 按钮。

- **点击「重新处理」**：重新执行一次预处理。**什么时候需要**：
  - 在「系统概览」页切换过数据库 —— 新库必须重新处理一次。
  - 仿真库内容有更新（追加了新数据）。
  - 后台补充了立场标注、决策中间变量等新字段。

> 一个仿真库只需处理一次，结果持久化在库里；下次打开直接是状态 B。

## 步骤 1 · 舆情生命周期页

回答的问题：**这场舆情整体是怎么走的？各阶段有什么不同？**

页面把舆情过程自动切成四个阶段：**潜伏期 → 爆发期 → 扩散期 → 衰退期**
（依据事件量随时间的曲线自动划分，规则见附录）。

### 控件 1：拆解维度（下拉框）

决定页面下方两个构成图「按什么维度拆开看」。可选 7 项，**切换后下方两图立即重新计算**，
四阶段卡片与主轴图不受影响。

| 选项 | 选了之后两个构成图变成…… | 适合回答 |
|---|---|---|
| 行为类型 | 按 发帖/转发/评论/点赞/刷新/搜索…… 拆分 | 各阶段大家在「做什么」？是发声为主还是围观为主 |
| 情感极性 | 按 正面/中性/负面 拆分 | 各阶段情绪如何变化，负面是否在某阶段抬头 |
| 关键角色 | 按 意见领袖/讨论发起者/活跃用户/普通传播者/边缘用户 拆分 | 各阶段是谁在推动，是 KOL 带头还是普通用户扩散 |
| 影响力分层 | 按 头部/腰部/长尾 拆分 | 各阶段头部和长尾的参与比例 |
| 行为标签 | 按 内容生产者/活跃互动者/潜水观望/沉默用户 拆分 | 各阶段沉默用户是否被「激活」 |
| 话题 | 按帖子话题标签拆分 | 各阶段讨论焦点如何转移（单一议题仿真库此项区分度低） |
| 推荐驱动 | 按「推荐驱动 / 自然到达」拆分 | 各阶段有多少互动是被推荐算法触发的 |

> 说明：刷新、搜索等「软行为」没有情感/话题属性，在按情感或话题拆解时会归入「其他/无情感」一类。

### 控件 2：四阶段卡片（可点击）

每张卡片显示该阶段的时间区间、事件量、活跃用户数、涉及内容数、情感构成条。

- **点击某张卡片**：
  - 该阶段被设为「当前聚焦」，卡片高亮金色边框，控制栏右侧出现「当前聚焦：XX」。
  - 这个聚焦状态会被记住，**进入关键群体页、关键用户页时自动沿用**（两页的「聚焦阶段」会预填为它）。
- **再点另一张卡片**：聚焦切换到新阶段。
- **点击控制栏的「取消」**：清除聚焦，后续页面恢复为「全部阶段」。

### 控件 3：各阶段构成对比图上的「绝对量 / 占比」切换

- **绝对量**：纵轴是事件条数，能看出哪个阶段「量大」。
- **占比**：每个阶段归一化到 100%，能看出**结构差异**——比如爆发期负面占比是否明显高于潜伏期。

### 三张图的含义

1. **生命周期主轴图**：事件量曲线 + 平均情感分曲线 + 四阶段背景色带。把握整体节奏与情绪基调。
2. **构成演化流图**：逐小时的堆叠面积图，看所选维度的构成怎样平滑演化。
3. **各阶段构成对比图**：四个阶段并排的堆叠柱，直接对比维度构成在阶段间的跳变。

### 出口

底部「进入关键群体识别 →」按钮，跳转到步骤 2。

## 步骤 2 · 关键群体识别页

回答的问题：**在（聚焦的）这个阶段里，哪一类人群在主导舆情？**

### 控件 1：群体划分维度（下拉框）

决定「把所有用户按什么特征切成群体」。**切换后立即重新查询**。可选 9 项：

| 选项 | 把人群切成…… |
|---|---|
| 关键角色 | 意见领袖 / 讨论发起者 / 活跃用户 / 普通传播者 / 边缘用户 |
| 影响力分层 | 头部 / 腰部 / 长尾 |
| 行为标签 | 内容生产者 / 活跃互动者 / 潜水观望 / 沉默用户 / 普通参与者 |
| 社群 | 按关注网络自动检测出的社群编号 |
| 性别 / 地区 / 职业 / 账号类型 / 内容偏好 | 按对应的用户画像字段（依赖画像数据，缺失时多为「未知」） |

### 控件 2：聚焦阶段（下拉框，可清空）

- **选某个阶段**：群体的**行为类指标**（事件量、平均情感、推荐驱动占比）只统计该阶段；
  群体的**规模/影响力类指标**（人数、平均影响力）不随阶段变化（它们是用户固有属性）。
- **留空（全部阶段）**：行为类指标统计全过程。
- 若在生命周期页聚焦过某阶段，这里会出现「（生命周期页锁定了「XX」**套用**）」——点「套用」即可一键填入。

### 控件 3：条件组合（动态筛选）

这是「按不同条件组合筛选」的核心。点「＋ 添加条件」可加任意多行，每行：

1. 左侧下拉：选一个用户特征（社群/影响力分层/行为标签/角色/性别/地区/职业/账号类型/内容偏好）。
2. 右侧下拉：在该特征下多选一个或多个取值。
3. 「移除」删除该行。

- **多行条件之间是「且」关系**：例如「职业 = 媒体」且「行为标签 = 内容生产者」，
  只有同时满足的用户才会进入群体统计。
- **效果**：条件会缩小「被纳入统计的用户范围」，于是所有群体的人数、影响力、事件量都随之变化，
  关键度排名也会重排。
- 条件留空（某行没选取值）则该行被忽略。

### 控件 4：应用筛选（按钮）

点击后用「群体划分维度 + 聚焦阶段 + 条件组合」重新查询，三块视图同时刷新。
（切换「群体划分维度」「聚焦阶段」会自动触发，改条件组合后需手动点此按钮。）

### 三块视图的含义与联动

1. **群体分布散点图**：横轴=群体总活跃度，纵轴=群体平均影响力，气泡大小=人数，颜色冷暖=关键度。
   **右上角的大暖色气泡 = 关键群体**。
   - **点击气泡**：携带该群体作为筛选条件跳转到关键用户页。
2. **群体关键度排名**：关键度 = 规模×25% + 平均影响力×30% + 活跃度×20% + 事件量×25%（标题旁 `?` 有提示）。
3. **群体明细表**：每个群体一行，含人数、关键度、平均影响力、事件量、意见领袖数、情感构成等，列可排序。
   - **点击任一行**：等同于点击该群体气泡，下钻到关键用户页。

### 出口

点击任意群体（气泡或表格行）→ 跳转步骤 3，并自动把该群体作为条件带过去。

## 步骤 3 · 关键用户识别页

回答的问题：**在（聚焦阶段 / 选定群体）里，具体哪些人是核心人物？**

若从关键群体页跳转而来，条件组合里会自动出现一条「来自群体分析」的预置条件，聚焦阶段也会一并带入。

### 控件 1：关键角色（下拉框）

- **全部**：不限角色。
- **意见领袖 / 讨论发起者 / 活跃用户 / 普通传播者 / 边缘用户**：只看该角色的用户。
  角色由数据预处理阶段判定（规则见附录）。

### 控件 2：排序依据（下拉框）

决定明细表与排名图按什么排序，**切换后立即重排**。7 项：

| 选项 | 含义 / 适合找的人 |
|---|---|
| 影响力分数 | 综合粉丝、被转发、获赞、发帖、网络地位的加权分——综合最有影响力的人 |
| PageRank | 关注网络中的结构地位——「被重要的人关注」的人 |
| 粉丝数 | 单纯粉丝多的人 |
| 被转发数 | 内容被转发最多——传播力最强的人 |
| 获赞数 | 内容最受认可的人 |
| 活跃度 | 行为事件最多——最「勤」的人 |
| 原创数 | 发原创帖最多——内容产出最多的人 |

### 控件 3：聚焦阶段（下拉框，可清空）

- **选某阶段**：只保留**在该阶段有过行为**的用户（在该阶段「潜水」的人会被排除）。
- **留空**：不按阶段过滤。

### 控件 4：数量

明细表与查询返回的用户条数上限（10–200）。排名图固定取其中前 20。

### 控件 5：条件组合

与关键群体页完全一致：多行「用户特征 = 取值」，行间「且」关系，缩小用户范围。
可在「来自群体」的预置条件上继续叠加，进一步收敛。

### 控件 6：应用筛选

用上述全部条件重新查询。（角色、排序、阶段、数量改动会自动触发；条件组合改动后需手动点。）

### 三块视图

1. **角色构成**（环形图）：当前筛选结果里各角色的人数占比。
2. **关键用户排名**（条形图）：前 20 名，长度=「排序依据」所选指标的值。
3. **关键用户明细表**：每人一行，含角色、影响力、分层、粉丝、PageRank、原创/转发/被转发/获赞、
   活跃度、行为标签、社群等，列可排序。
   - **点击任一行**：弹出「个体溯源」面板，进入步骤 4。

## 步骤 4 · 个体溯源（弹窗）

在关键用户明细表点击某一行后弹出，回答：**这个人到底是怎么参与这场舆情的？**

面板内容：

| 区块 | 含义 |
|---|---|
| 画像栏 | 角色、影响力分层、行为标签、所属社群、粉丝/关注、影响力分、被转发、获赞、活跃度、性别、职业 |
| 行为构成（环形图） | 此人全过程各类行为（发帖/转发/评论/点赞/刷新……）的占比 |
| 各阶段活跃度（柱状图） | 此人在潜伏/爆发/扩散/衰退四阶段分别有多少行为——看他是早期发起型还是后期跟风型 |
| 行为轨迹（堆叠柱） | 逐小时的行为序列，按行为类型堆叠——看他的参与节奏 |
| 发布内容列表 | 最近的原创/转发，带情感标签、所属阶段、点赞/转发/评论数、传播级联规模与深度 |

关闭弹窗即可回到明细表继续看其他人。

## 完整流程示例（串起来）

1. **步骤 0**：打开「舆情生命周期」，点「开始预处理」，等待就绪。
2. **步骤 1**：拆解维度选「情感极性」，发现**爆发期负面占比明显抬升** → 点击「爆发期」卡片聚焦。
3. **步骤 2**：进入「关键群体识别」，聚焦阶段已自动是「爆发期」；群体划分维度选「职业」，
   再加条件「情感倾向相关的行为标签」；在散点图右上角发现「媒体」群体关键度最高 → 点击该气泡。
4. **步骤 3**：自动带入「职业=媒体 + 爆发期」；排序依据选「被转发数」，
   锁定前几名传播力最强的媒体账号。
5. **步骤 4**：点击排名第一的账号，在个体溯源里确认它在爆发期集中发帖、内容以负面为主、
   单条帖子级联规模很大 —— 完成从宏观舆情到关键个体的闭环定位。

## 附录

### A. 维度词典

**用户维度**
- 社群：依据关注网络自动检测的社群编号。
- 影响力分层：头部（影响力前 10%）/ 腰部（10–40%）/ 长尾（其余）。
- 行为标签：内容生产者（以发帖转发为主）/ 活跃互动者（以评论点赞为主）/ 潜水观望（以刷新搜索为主）/ 沉默用户（以「不操作」为主）/ 普通参与者。
- 关键角色：见 C。
- 性别 / 地区 / 职业 / 账号类型 / 内容偏好：来自用户画像数据，缺失时为「未知」。

**内容维度**
- 话题：帖子的 `#话题#` 标签，无标签时按关键词归类。
- 情感极性：正面 / 中性 / 负面。
- 立场：预留字段，待标注后启用。

**行为维度**
- 行为类型：发帖、转发、评论、点赞、关注、刷新、搜索、看热搜、不操作、注册。
- 推荐驱动：该互动的对象帖子是否曾被推荐给该用户。

**时间维度**
- 舆情阶段：潜伏期 / 爆发期 / 扩散期 / 衰退期。
- 小时：按自然小时聚合。

### B. 度量含义
行为数、独立用户数、涉及内容数、平均情感分（-1~1）、正面占比、负面占比、推荐驱动占比。

### C. 关键角色判定规则
| 角色 | 判定条件（按优先级） |
|---|---|
| 意见领袖 | 影响力分层=头部，且被转发或获赞 > 0 |
| 讨论发起者 | 发过「级联规模 ≥ 3」的原创帖 |
| 活跃用户 | 行为事件数处于全体前 15% |
| 普通传播者 | 有过转发行为 |
| 边缘用户 | 以上都不满足 |

### D. 影响力分数公式
`log(粉丝+1)×3 + log(被转发+1)×2.5 + log(获赞+1)×1.5 + log(原创数+1)×2 + PageRank×50`

### E. 生命周期分期算法
统计事件量的逐小时曲线并做 3 点平滑：
- **潜伏期**：从开始到事件量首次达到峰值 25% 之前。
- **爆发期**：从该点上升至峰值。
- **扩散期**：从峰值到事件量回落至峰值 50% 之前的高位平台。
- **衰退期**：其余。
数据量过少时退化为按事件数四等分。

### F. 跨页状态
- 在生命周期页聚焦的阶段、在群体页选中的群体，都会自动带入下一页，无需手动重复设置。
- 切换数据库后需重新执行步骤 0 的预处理。
